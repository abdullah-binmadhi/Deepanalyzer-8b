# DeepAnalyze: Architecture & Compliance FAQ

Comprehensive answers regarding unflattened ERP masking, data privacy, and execution security.

---

### Q1: How does DeepAnalyze protect messy, unflattened ERP spreadsheets with wrong or missing columns?
**Answer:** Standard PII scanners evaluate clean column headers (e.g. `customer_name`), which fail completely on unflattened ERP reports where client names and invoice numbers are buried in row cells under headers like `Date : From 1/8/2025`. DeepAnalyze applies **Cell-Level Geometric Masking**: it preserves structural layout keywords (`Doc. No`, `Doc Date`, `Seq`, `GL Code`, `:`) so an external AI can understand the hierarchical geometry, while masking all client names to `XXXX`, invoice numbers to `XX-99999`, and figures to `9,999.00`.

### Q2: What happens if a user selects "Not Sure" for the compliance framework or dataset type?
**Answer:** DeepAnalyze contains built-in statutory and geometric heuristics. If "Not Sure" is chosen for the compliance framework, it automatically maps the user's operating country to the governing national statute (e.g., Saudi Arabia -> Saudi PDPL & NDMO Standards; Poland -> GDPR & UODO). If "Not Sure" is chosen for the dataset type, it inspects colon frequencies, multi-level headers, and ragged structures to detect whether the dataset is an unflattened ERP report or clean tabular data.

### Q3: How does the interactive value teaching feature work?
**Answer:** If the scanner misses an internal business code (e.g., General Ledger Code `500-000` or custom sequence number `10000`), the user simply enters the column name and one example value. DeepAnalyze infers the regex pattern and length constraints on the fly, registers a dynamic token rule, and re-masks all matching occurrences across thousands of rows.

### Q4: What is the difference between an encrypted duplicate file and a clipboard payload?
**Answer:** 
* **Encrypted Duplicate File (`[name]_anonymized.xlsx`):** A complete duplicate of the original spreadsheet saved to disk where 100% of the row/column structure is retained, but every sensitive entity and dollar amount is replaced with safe surrogate values. You can upload this entire file to cloud models or external partners.
* **Clipboard Payload:** A lightweight 5-row differential synthetic mock and prompt instructions copied directly to your clipboard for quick paste into ChatGPT/Claude.

### Q5: How does the interactive code airlock handle errors in AI-generated code?
**Answer:** When cloud AI code is pasted into single `.py` or multi-block `.ipynb` mode, DeepAnalyze catches any execution exceptions in local RAM. Instead of crashing the IPython kernel, it displays the exact error message and prompts the user: `"Would you like to paste the corrected code? [y/N]"`. This allows the user to iteratively debug with the cloud AI until the code executes cleanly.

### Q6: How does DeepAnalyze ensure zero data leakage during execution?
**Answer:** The external cloud AI is given only the anonymized duplicate file or synthetic mock. The Python cleaning script generated by the AI is intercepted by the AST Security Firewall (`firewall.py`), which blocks network libraries (`socket`, `requests`, `urllib`), environment variable access (`os.environ`), and destructive OS commands. The code runs locally in RAM against the real data, restores genuine values, and leaves zero forensic trace on disk.

### Q7: What if the cloud AI generates code using Pandas and NumPy instead of Polars?
**Answer:** DeepAnalyze is equipped with a native Dual-Engine execution layer. Frontier cloud LLMs (ChatGPT, Claude, Cursor) overwhelmingly generate data wrangling code using `pandas` (`pd`) and `numpy` (`np`). DeepAnalyze automatically pre-injects `pandas as pd`, `numpy as np`, and `polars as pl` into the local execution scope. Furthermore, the airlock detects whether incoming code uses Pandas idioms (e.g. `df.iloc`, `df.apply`, `df['col']`, `pd.to_datetime`, `np.where`) or Polars expressions (`pl.col`, `.with_columns`), and seamlessly provides `df` in the expected representation. In-memory token vault detokenization, snapshot rollbacks, and file exports operate with 100% fidelity on both Pandas and Polars DataFrames.

### Q8: What if I am not a programmer and want to clean the spreadsheet in Microsoft Excel using Power Query instead of Python?
**Answer:** DeepAnalyze incorporates a **Dual-Track Delivery**:
* **Track A (Automated Python/Pandas in RAM):** 1-click execution in memory that immediately produces `Clean_file.xlsx`.
* **Track B (Power Query M-Code & Step-by-Step UI Guide):** Generates ready-to-paste Power Query M-code for Excel's Advanced Editor, accompanied by a comprehensive click-by-click UI walkthrough with exact formulas. This empowers accountants, financial controllers, and non-analysts to execute or modify the data transformation directly in Excel without ever having to touch a terminal or write Python. Moreover, once saved in Excel, the query can be refreshed on future monthly ERP exports with a single click.

### Q9: Why did my previous anonymized Excel export have missing columns, and how does DeepAnalyze guarantee full column fidelity?
**Answer:** Traditional spreadsheet parsers infer column count from the first few rows. In unflattened ERP spreadsheets, top metadata rows often contain only 2 or 3 cells (e.g. `Date : From 1/8/2025`), leading naive engines to truncate the rest of the spreadsheet. DeepAnalyze uses a dedicated multi-column Excel ingestion engine (`pd.read_excel(clean_path, header=None)`) that inspects the entire sheet geometry, preserves all 16+ columns, handles mixed data types across ragged rows, and ensures the anonymized export retains 100% of the columns, row hierarchy, and cell relationships.

### Q10: How does DeepAnalyze prevent re-identification through quasi-identifiers?
**Answer:** Masking direct identifiers (names, national IDs) is not always enough if demographic combinations (e.g. Age, Gender, Postal Code) remain unique. DeepAnalyze scans for quasi-identifiers, calculates the minimum equivalence class size ($k_{\min}$), and verifies that $k \ge 5$. Furthermore, it evaluates $l$-diversity across sensitive columns (such as diagnoses or salaries) so that each equivalence class contains at least $l \ge 2$ distinct sensitive values, mitigating demographic linkage and homogeneity attacks.

### Q11: How do the Real-Time Quality Scorecard and automated Pytest generator work?
**Answer:** In Step 12, DeepAnalyze generates a side-by-side tabular diff comparing the raw input dataset against the transformed output. It measures row deduplication, null reduction percentage, column standard hygiene (converting messy headers to clean snake_case), and type validity to compute a deterministic 0-100 Quality Score. Concurrently, it writes a runnable `test_clean_pipeline.py` file containing assertions for schema integrity, null constraints, domain validity, and pipeline idempotency, ready for CI/CD integration.
