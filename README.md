# DeepAnalyze: Zero-Code Compliance Air-Gap Gateway

DeepAnalyze is an open-source, deterministic Data Leak Prevention (DLP) engine and compliance air-gap gateway for Jupyter and IPython. It enables data teams, financial analysts, and healthcare researchers to use frontier cloud AI models (ChatGPT, Claude, Cursor) on **messy, unflattened ERP spreadsheets, invoices, and clinical records** without exposing confidential business data, personal identities, or proprietary records.

The engine enforces statutory anonymization in local volatile RAM, generates zero-risk synthetic payloads or full encrypted duplicate files for cloud LLMs, provides an interactive `.py` / `.ipynb` code execution airlock with automatic error retry, and reconciles returned transformations locally with zero data leakage.

---

## Key Capabilities

* **Zero-Code Interactive Wizard:** The user writes zero Python code. The conversational wizard guides data ingestion, compliance resolution, layout masking, and execution.
* **"Not Sure" Auto-Detection:** Automatically detects statutory frameworks (Saudi PDPL, GDPR, HIPAA, UK DPA) and unflattened ERP architectures (ragged headers, colon metadata, unpivot structures).
* **Full-File Deep Scan & Geometric Masking:** Evaluates entire files cell-by-cell. Masks numbers, codes, and names while strictly preserving structural layout anchors (`Doc. No`, `Doc Date`, `Seq`, `GL Code`, `:`).
* **Interactive Disambiguation & Pattern Learning:** Allows users to teach custom patterns on the fly (e.g. `Seq -> 10000`, `GL Code -> 500-000`) to re-mask specific fields across thousands of rows.
* **Encrypted Duplicate Export:** Exports a duplicate spreadsheet (e.g. `[filename]_anonymized.xlsx`) with 100% of the ERP layout and all 16+ columns preserved but 0% real PII/figures.
* **Excel Power Query Dual-Track (For Non-Programmers):** In addition to automated Python execution in RAM, DeepAnalyze generates ready-to-paste Power Query M-code (`powerquery_script.m`) and a comprehensive click-by-click UI formula guide (`powerquery_guide.md`). Accountants and business users can execute and refresh transformations natively in Microsoft Excel without writing code.
* **Interactive Code Execution Airlock:** Accepts cloud AI code in a single script (`.py`) or interactive notebook (`.ipynb`), audits syntax with an AST Firewall, executes locally in RAM, and includes an interactive error retry loop.
* **Pandas & NumPy Dual-Engine:** Seamlessly executes Pandas and NumPy code generated by cloud models (e.g. `df.iloc`, `df.apply`, `df['col']`, `pd.to_datetime`, `np.where`), automatically adapting DataFrame representations between Pandas and Polars without dialect errors.
* **Volatile Memory Air-Gap:** Lookup dictionaries and sensitive data exist exclusively in volatile RAM. No unencrypted intermediate data touches disk.

---

## End-to-End Workflow

1. **Ingest & Profile:** Point to any CSV or Excel file (including ragged ERP exports). DeepAnalyze sanitizes paths and binds the dataset to an in-memory variable.
2. **Auto-Detect & Classify:** Answer origin country and compliance questions (or choose "Not Sure" for intelligent auto-detection). Review the 3-tier risk assessment table.
3. **Deep Scan & Teach:** DeepAnalyze scans all cells, summarizes unique masked patterns, and lets you teach additional field rules interactively.
4. **Anonymized Export / Clipboard:** Download an encrypted duplicate `.xlsx` file to disk or copy a 5-row synthetic schema mock to your clipboard.
5. **External AI Processing:** Share the anonymized file or prompt payload with ChatGPT, Claude, or Cursor to generate cleaning and unpivoting code.
6. **Code Airlock & Local Execution:** Paste the code into `.py` or `.ipynb` mode. DeepAnalyze audits the AST, executes the code locally in RAM, handles any errors interactively, detokenizes original values, and exports the final clean spreadsheet.
